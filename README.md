# Mecanica-estadistica
Componente computacional de los trabajos realizados en Mecanica estadistica

El archivo "AlgoritmoMetropolis.py" contiene la implementacion del algoritmo de Metropolis. Los parametros usados y documentados en el informe se encuentren definidos manualmente en la primera seccion del codigo, sin embargo, estos se pueden modificar libremente. El codigo produce la figura de convergencia de energia para los parametros seleccionados y la grafica de magnetizacion vs temperatura. Nuevamente se puede cambiar libremente el rango de temperaturas considerado y la separacion de las temperaturas. La primera grafica mencionada tambien produce a forma de texto impreso la magnetizacion promedio y la energia por sitio encontrada tras convergencia.
